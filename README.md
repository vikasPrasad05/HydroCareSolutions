# HydroCareSolutions

Official web platform and management portal for HydroCare Solutions — Manufacturers of food-grade absorbent meat, poultry, seafood, and fruit pads.

## Tech Stack
- **Framework:** Astro 4
- **Database:** Cloudflare D1 (SQLite) with local JSON fallback
- **Styling:** Modern Vanilla CSS Design System with Blueprint Grid Aesthetics
- **Architecture:** Server-Side Rendered (SSR) & Static Hybrid

## Project Setup
```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

## Production Build
```bash
npm run build
```
